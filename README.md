Асинхронный микросервис для детекции автомобилей на видео с использованием FastAPI, Taskiq, Redis, PostgreSQL и YOLOv8.

 ## Стек 
- **FastAPI** — веб-сервер и API.
- **Taskiq + Redis** — брокер сообщений и воркер для фоновой обработки видео.
- **PostgreSQL + SQLAlchemy 2.0 (asyncpg)** — хранение результатов детекции.
- **YOLOv8 + OpenCV** — ML-инференс и отрисовка bounding boxes.

- API Эндпоинты

    POST /detect/video — Загрузка видеофайла и постановка в очередь (возвращает task_id).

    GET /tasks/{task_id} — Проверка статуса выполнения задачи.

    GET /detections — Получение пагинированного списка результатов с путями к сохраненным кадрам.

    GET /media/detections/{filename} — Получение изображения с отрисованными рамками.
